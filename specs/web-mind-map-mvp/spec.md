# Web Mind Map MVP 需求规格

## 目标

交付一个可在桌面浏览器中独立使用的单用户思维导图编辑器。用户能够高效地创建、编辑、组织、保存、查找和导出思维导图，核心体验参考 XMind 的基础思维导图能力，但不要求界面、文件格式或全部高级功能与 XMind 一致。

本 MVP 必须是可持续使用的编辑器，而不是只展示少量固定节点的演示页面。它同时为后续响应式 Web、PWA、小程序和移动端复用保留清晰的产品边界。

## 用户

- 需要快速梳理想法、任务、知识结构和会议内容的个人用户。
- 习惯使用键盘连续录入大量主题的效率型用户。
- 需要将导图保存到本地、跨浏览器会话继续编辑或导出分享的用户。
- 首版不包含团队管理员、协作者、访客审阅者等多人角色。

## 用户场景

### 1. 创建和管理导图

用户进入应用后可以新建空白导图，为导图命名，并在导图列表中打开、重命名、复制或删除已有导图。刷新或重新打开浏览器后，未被删除的导图仍可继续编辑。

### 2. 键盘快速构建结构

用户选中一个主题后，可以用键盘创建同级主题和子主题、修改文字、删除主题，并连续录入多个层级。所有核心编辑操作均可撤销和重做。

### 3. 鼠标调整导图

用户可以选择单个或多个主题，拖动主题及其子树改变顺序或父级。用户可以平移和缩放画布、适配全部内容，并快速定位当前选中的主题。

### 4. 补充主题信息和视觉表达

用户可以设置主题的基础样式、颜色、图标或标记，添加优先级、状态、备注和链接，并折叠或展开较大的分支。

### 5. 查找和整理大型导图

用户可以搜索主题文本并在匹配结果之间跳转。面对较大导图时，可以通过折叠分支、居中选中项和适配画布保持可操作性。

### 6. 本地保存、导入和导出

用户的修改会自动保存。用户可以导出可再次编辑的内部 JSON 文件，也可以导出 PNG 或 SVG 用于分享；之后可以重新导入内部 JSON，并继续编辑且不丢失受支持的数据。

## 范围内

### MVP 必需功能

#### 导图管理

- 新建、打开、重命名、复制和删除导图。
- 提供至少一个可直接编辑的默认导图或空白导图入口。
- 自动保存当前导图，并向用户显示保存中、已保存或保存失败状态。
- 删除操作需要二次确认，并明确其不可撤销范围。

#### 主题编辑

- 创建、选择、编辑文本、删除、复制、剪切、粘贴和复制副本。
- 创建同级主题和子主题。
- 同一父级下重新排序主题。
- 将主题及其完整子树移动到新的父级。
- 支持单选和基础多选，并可对多选主题执行删除、移动或基础样式修改。
- 删除父主题时同时处理其完整子树，并允许通过撤销恢复。
- 根主题不可被删除或移动为其他主题的子节点，但允许修改内容和样式。

#### 键盘操作

- `Enter` 创建同级主题。
- `Tab` 创建子主题。
- `Delete` 或 `Backspace` 删除选中主题；编辑文本时保持正常文字删除行为。
- 支持常用系统组合键完成撤销、重做、复制、剪切、粘贴和全选。
- 新建主题后直接进入可输入状态，提交后保持连续创建流程顺畅。
- 键盘焦点和当前选中状态对用户可见。

#### 画布与导航

- 采用稳定的从左到右树形布局。
- 支持鼠标拖动主题或子树调整层级和顺序，并在放置前显示目标反馈。
- 支持画布平移、放大、缩小、适配全部内容和居中当前选中主题。
- 提供当前缩放比例或等价的缩放反馈，并限制在可用范围内。
- 折叠和展开分支；折叠状态保存后可恢复。
- 连接线能够随布局和节点移动正确更新。

#### 主题内容与表现

- 支持纯文本主题标题，并正确处理空白、换行和较长文本。
- 支持一组预设主题样式，包括文字样式、主题颜色和背景或边框表现。
- 支持图标或标记，以及优先级和状态标记。
- 支持为主题添加、编辑、查看和删除备注。
- 支持为主题添加、编辑、打开和删除链接；打开外部链接前需有明确的用户操作。
- 选中、悬停、编辑、拖动和折叠状态应有可区分的视觉反馈。

#### 搜索

- 按主题文本执行不区分大小写的包含搜索。
- 显示匹配数量，并支持跳转到上一个或下一个结果。
- 跳转结果时展开其祖先分支、选中结果并将其移入可视区域。
- 无结果时给出明确反馈，清空搜索后恢复正常显示。

#### 数据与文件

- 浏览器刷新、意外关闭页面或重新进入应用后，可恢复最近一次成功自动保存的数据。
- 支持导出当前导图为内部 JSON 文件。
- 支持导入本产品导出的有效 JSON 文件，并在覆盖已有内容前明确提示。
- 内部 JSON 导入导出后，导图名称、完整主题树、顺序、内容、样式、标记、备注、链接和折叠状态保持一致。
- 对无效、损坏或不受支持的 JSON 文件给出错误提示，且不破坏现有导图。
- 支持导出当前导图为 SVG 和 PNG；导出结果包含完整导图，不受当前视口裁切影响。

#### 可靠性与可用性

- 所有改变导图内容或结构的核心编辑操作都可撤销和重做。
- 执行新编辑后，已撤销操作对应的重做历史被清除。
- 空导图、单节点导图和至少 500 个主题的导图均不会导致应用崩溃。
- 50 个主题的导图可通过键盘连续创建，无明显阻塞或输入丢失。
- 500 个主题的导图仍可完成平移、缩放、搜索、折叠和自动保存。
- 用户操作失败时提供可理解的反馈，且不得以静默失败的方式丢失已有数据。

### MVP 增强功能

以下能力属于首版范围内的增强项，但不阻塞第一份可用 MVP 发布：

- 在两个主题间创建、编辑和删除关系线。
- 为连续分支添加和删除边界。
- 为一组同级主题添加概要或分组说明。
- 一键整理当前导图，使节点间距和顺序恢复清晰。

## 范围外

- 小程序客户端、原生或混合移动客户端、桌面原生客户端。
- 响应式移动端专项适配和 PWA 安装能力。
- 登录、账号体系、云同步、多设备同步和服务端存储。
- 实时协作、评论、分享权限、团队空间和版本协同。
- AI 生成、AI 总结、自动扩写或提示词创建导图。
- 完整 XMind 文件导入导出或与 XMind 的像素级界面一致性。
- OPML、Markdown、PDF、Word、PowerPoint 等额外格式兼容。
- 多种复杂布局、自由画布、流程图、组织结构图和通用白板。
- 自定义模板市场、插件系统、付费、角色权限和企业管理。
- 图片、附件、音视频等大型富媒体嵌入。

## 验收标准（Acceptance Criteria）

### AC-01 导图生命周期

给定用户已进入应用，当用户新建、命名、关闭并重新打开一个导图时，导图名称及最后一次成功保存的内容保持一致；用户也可以复制、重命名和经确认后删除该导图。

### AC-02 主题结构编辑

给定任意非根主题被选中，当用户新增同级或子主题、修改文本、复制、粘贴、重新排序或移动父级时，界面中的树结构立即反映结果，保存后重新打开仍保持相同结构和顺序。

### AC-03 键盘连续录入

给定画布拥有键盘焦点且主题被选中，当用户使用 `Enter`、`Tab`、文字输入和删除快捷键时，可以在不依赖工具栏的情况下建立和修改多层主题结构，且输入框中的删除按键不会误删主题。

### AC-04 拖动主题

给定一个非根主题及其子树，当用户将它拖到合法的新位置时，放置目标在操作前可识别，放置后主题的父级或顺序正确改变，子树结构保持完整；拖到自身或其后代时操作被拒绝且数据不变。

### AC-05 撤销与重做

给定用户已完成一组主题内容、结构和样式编辑，当用户逐步撤销再重做时，每一步均恢复到对应状态；刷新后至少已自动保存的最终状态保持一致，不出现部分恢复或孤立主题。

### AC-06 画布导航

给定导图内容超出视口，当用户平移、缩放、适配全部或居中选中主题时，可以到达全部可见主题；缩放不越过允许范围，适配全部不会裁掉完整节点或连接线。

### AC-07 折叠与展开

给定一个含后代的主题，当用户折叠该主题时，其后代不显示但数据仍存在；再次展开后结构和内容恢复，保存并重新打开后折叠状态保持一致。

### AC-08 主题附加信息

给定主题被选中，当用户修改预设样式、标记、优先级、状态、备注或链接时，变更可查看、可再次编辑、可撤销，并在重新打开导图及 JSON 往返后保持一致。

### AC-09 搜索定位

给定导图中存在多个匹配主题且部分位于折叠分支，当用户搜索并切换结果时，应用显示正确匹配总数，展开必要祖先、选中对应主题并将其移到可视区域；无匹配时显示空结果反馈。

### AC-10 自动保存与恢复

给定用户完成编辑并出现保存成功状态，当用户刷新或关闭后重新进入时，最近成功保存的数据被恢复；若保存失败，应用明确告知用户，且不会错误显示为已保存。

### AC-11 JSON 往返

给定一个包含多层主题、顺序、样式、标记、备注、链接和折叠状态的导图，当用户导出 JSON 后重新导入时，所有受支持数据保持等价且仍可继续编辑。

### AC-12 非法导入保护

给定用户选择了损坏、格式不正确或版本不受支持的文件，当导入失败时，应用说明失败原因，原导图和导图库不被覆盖或破坏。

### AC-13 图片导出

给定一个超出当前视口的导图，当用户分别导出 SVG 和 PNG 时，文件包含完整可见结构、主题文字、样式、标记和连接线，且没有因当前缩放或视口造成裁切。

### AC-14 规模可用性

给定一个包含 500 个主题的有效导图，当用户执行打开、平移、缩放、搜索、折叠和自动保存时，应用不崩溃且交互仍可完成；给定 50 个主题的录入任务，键盘连续创建过程中不丢失输入。

### AC-15 数据隔离

给定导图库中存在多个导图，当用户编辑、复制、导入或删除其中一个时，其他导图的内容不发生非预期变化。

## 边界情况

- 新用户首次进入，没有任何已保存导图。
- 导图只包含根主题，或主题标题为空、仅含空格、包含换行或非常长。
- 同一父级下存在大量主题，或导图深度很大。
- 用户尝试删除根主题、将主题移动到自身或后代、重复粘贴同一子树。
- 多选中同时包含父主题和其后代，随后执行删除、移动或样式修改。
- 编辑文本时触发全局快捷键，或中文输入法组合输入期间按下快捷键。
- 用户拖动过程中离开画布、按 `Esc`、释放在非法区域或窗口失去焦点。
- 搜索结果位于折叠分支，匹配文本包含大小写差异、中文、空格或特殊字符。
- 自动保存期间继续编辑，或连续快速修改导致多个保存请求重叠。
- 浏览器存储空间不足、存储权限不可用、数据写入失败或旧数据读取失败。
- 导入空文件、超大文件、错误文件类型、重复 ID、循环结构、缺失字段或未来版本文件。
- PNG/SVG 导出时导图为空、尺寸极大、包含长文本或特殊字符。
- 用户连续撤销到历史起点、重做到终点，或撤销后产生新的编辑分支。
- 剪贴板权限不可用，或剪贴板内容不是本产品可识别的主题数据。

## 假设

- 首版只保证最新稳定版桌面 Chrome 和 Edge 的核心体验；Firefox 和 Safari 作为尽力兼容目标。
- 首版为本地优先、单设备、单用户产品，不需要账号或网络连接即可完成核心编辑。
- 浏览器本地数据是 MVP 的主要持久化来源；清理浏览器数据可能导致本地导图丢失，因此内部 JSON 导出承担用户主动备份能力。
- 主题标题以纯文本为主；“rich-enough styling”指预设文字和主题视觉样式，不包含任意富文本排版。
- 多选为基础能力，至少支持通过平台常用修饰键逐个增减选择，并对选中集合执行有限的批量操作。
- XMind 仅作为基础功能和交互效率参考，不构成文件格式、视觉设计或全部行为兼容承诺。
- 关系线、边界、概要和一键整理属于 MVP 增强项，可在必需功能稳定后纳入同一版本周期。
- 性能验收以主流近三年桌面设备和最新稳定版浏览器为基准，不承诺低端移动设备上的 500 主题体验。
- 后续平台扩展是产品方向，但不会在本规格中增加小程序或移动端用户界面需求。
