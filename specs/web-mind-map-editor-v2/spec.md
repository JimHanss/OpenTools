# Web Mind Map Editor V2 需求规格

## 目标

在已完成的 Web Mind Map MVP 基础上，继续完善思维导图的专业编辑能力，使用户能够像使用成熟思维导图工具一样，高效调整主题层级、切换导图结构、组织语义信息、插入富内容并精细控制视觉样式。

本阶段参考 Xmind 的高频编辑能力，但不追求完整复制 Xmind，也不要求界面、文件格式或全部高级功能与 Xmind 一致。已有 MVP 功能必须继续可用，现有本地导图必须能够无损打开和继续编辑。

本阶段仍以桌面 Web、单用户、本地优先为交付目标，并继续保持领域模型、Command、布局、渲染、存储和平台 adapter 的边界，为后续 PWA、小程序和移动端复用保留空间。

## 用户

- 已经使用当前 MVP 创建导图，希望进行更复杂结构和视觉表达的用户。
- 需要通过思维导图编写文章大纲、项目计划、课程笔记、知识体系和会议纪要的个人用户。
- 习惯使用键盘连续录入，并希望减少鼠标操作的效率型用户。
- 需要通过标签、编号、筛选和分支聚焦管理大型导图的用户。
- 需要在主题中放置图片、公式或补充说明的学习、研究和技术用户。

## 用户场景

### 1. 快速重构主题层级

用户可以在现有主题上方插入父主题，只删除当前主题而保留并上移其子主题，并通过键盘移动同级顺序或调整层级。所有结构变化都能够撤销和重做。

### 2. 创建自由主题并整理零散想法

用户可以在画布空白位置创建 Floating Topic，自由拖动其位置，并在 Floating Topic 与普通树形主题之间转换。自动布局不应覆盖用户明确设置的自由位置。

### 3. 切换导图结构和方向

用户可以为整张导图选择从左到右、从右到左、双向平衡和从上到下等结构；也可以为主要分支选择不同结构。切换结构只改变布局表达，不改变主题内容、父子关系或同级顺序。

### 4. 使用标签、编号和 Callout 表达语义

用户可以为主题添加多个标签，通过标签突出或筛选相关主题；可以为同级主题添加自动编号或层级编号；可以添加 Callout 作为不占用主题层级的补充说明。

### 5. 在主题中加入图片和公式

用户可以从本地文件或剪贴板插入图片，调整展示尺寸并补充替代文本；用户也可以通过 LaTeX 源文本添加和编辑数学公式。图片和公式应跟随主题保存、移动、复制和导出。

### 6. 精细调整主题和分支样式

用户可以修改主题形状、字体、字号、字重、对齐、填充、边框以及分支线样式，并可以复制、粘贴、重置或批量应用样式。关系线、边界、概要和 Callout 也可以单独设置可见样式。

### 7. 聚焦和筛选大型导图

用户可以只查看当前分支并通过面包屑返回上级，也可以按主题文本、标签、Marker、优先级、状态或是否包含备注进行筛选和突出显示，而不删除或修改不匹配的主题。

### 8. 保存、恢复和导出高级编辑结果

所有新增编辑能力都进入统一 Command history、自动保存和内部 JSON。刷新、重新打开、JSON 往返以及 SVG/PNG 导出后，受支持的结构、内容和样式保持一致。

### 9. 使用基本编辑工具栏完成常用操作

用户进入编辑器后，可以通过清晰、分组的基本编辑工具栏完成撤销、重做、插入主题、删除、结构调整、内容增强、样式设置和画布导航。工具栏根据当前选择显示可用状态和快捷键提示，让不熟悉快捷键的用户也能发现并完成核心编辑操作。

## 范围内

### 已有功能回归基线

`web-mind-map-mvp` 中已经验收通过的导图管理、主题增删改、拖放、多选、撤销/重做、自动保存、搜索、基础样式、Marker、备注、链接、折叠、关系线、边界、概要、整理布局以及 JSON/SVG/PNG 导入导出，均属于本阶段的回归基线。

新增功能不得以删除、弱化或破坏已有功能为代价。

### 基本编辑工具栏

- 编辑器必须提供持续可发现的基本编辑工具栏，作为键盘快捷键之外的完整操作入口。
- 工具栏按功能分组，并至少提供以下操作：
  - **History**：Undo、Redo。
  - **主题**：创建同级主题、创建子主题、插入父主题、创建 Floating Topic、编辑文本、Duplicate、删除主题。
  - **结构**：调整同级顺序、提升/降低层级、折叠/展开、选择导图结构和方向、整理布局、聚焦分支。
  - **插入**：Marker、标签、Callout、关系线、边界、概要、备注、链接、图片和数学公式。
  - **样式**：主题/文字/边框/分支线样式、复制样式、粘贴样式、重置样式和导图 theme。
  - **视图**：缩小、当前缩放比例、放大、适配全部内容和居中选中主题。
- 默认直接显示最高频操作：Undo、Redo、创建同级主题、创建子主题、删除、插入菜单、结构菜单、样式入口和基础缩放。
- 低频操作可以收纳到有明确名称的分组菜单或“更多”菜单，但不能因此变成不可通过键盘访问。
- 导图标题、保存状态、返回导图库、导入和导出可以保留在 editor header；无需在基本编辑工具栏中重复出现。
- 工具栏根据选择状态更新：
  - 无主题选中时，禁用必须依赖主题的操作，并保留创建 Floating Topic、整图结构、theme 和视图操作。
  - Root 被选中时，禁用删除、插入父主题、提升层级和转换为普通子主题等非法操作。
  - 单个普通主题、Floating Topic、多选主题、关系线、边界、概要或 Callout 被选中时，只显示或启用适用于该对象的操作。
  - 多选状态下，批量样式、Marker、标签和删除等操作应说明作用范围；不支持批量执行的操作必须禁用。
- 禁用操作必须保持可见，并通过 tooltip 或等价说明解释当前不可用原因；不得允许点击后静默失败。
- 工具按钮必须提供图标和中文/英文可访问名称；仅图标按钮必须具有 tooltip，且 tooltip 应显示已配置的快捷键。
- 当前激活的工具、打开的分组菜单和已启用的布局/样式状态应有清晰视觉反馈。
- 工具栏可使用 `Tab`、方向键、`Enter`、`Space` 和 `Esc` 完成焦点移动、执行和关闭菜单；焦点不能在菜单关闭后丢失。
- 画布宽度不足时，工具栏可以将低频项目收纳到 overflow menu，但所有必需操作仍可访问，且不能遮挡画布的主要编辑区域。
- 通过工具栏触发的持久化编辑必须与快捷键、context menu 和 inspector 使用相同的 Command 行为，并具有相同的 undo/redo 结果。
- 工具栏操作不能直接绕过 validation、history 或 autosave，也不能维护独立于 editor session 的导图副本。

### 高级结构编辑

- 在选中主题上方插入新的父主题；原主题成为新父主题的子主题。
- 删除单个主题但保留其子主题；子主题按原顺序上移到被删除主题原来的位置。
- 使用键盘向前或向后移动同级主题。
- 使用键盘提升或降低主题层级，并阻止产生循环、孤立主题或无效 root。
- 支持通过直接输入、双击、`F2` 或等价键盘操作进入主题编辑。
- 主题宽度支持自动适应和用户指定宽度；指定宽度下文本自动换行。
- 结构编辑、宽度调整和批量操作均可撤销和重做。

### Floating Topic

- 在画布空白位置创建 Floating Topic，并立即进入文本编辑。
- Floating Topic 具有独立画布坐标，不强制参与树形自动布局。
- 支持拖动、复制、粘贴、删除、设置样式、添加 Marker/标签/备注/链接/图片/公式和 Callout。
- 支持将普通主题或完整子树转换为 Floating Topic。
- 支持将 Floating Topic 作为子主题放回普通树结构。
- 自动整理普通树结构时，不应改变 Floating Topic 的用户位置；用户可以单独选择“整理 Floating Topic”。

### 导图结构与方向

- 整张导图至少支持以下结构：
  - 从左到右 Logic Chart。
  - 从右到左 Logic Chart。
  - 左右双向平衡 Mind Map。
  - 从上到下 Tree/Org Chart。
- 双向结构支持将一级主题分配到左侧或右侧，并在重新排序后保持稳定。
- 主要分支可以覆盖整图默认结构，形成有限的 mixed structure；首版 mixed structure 至少支持 Logic Chart 与 Tree/Org Chart 的组合。
- 结构和方向属于可编辑导图数据，保存、复制、撤销/重做和 JSON 往返后保持一致。
- 切换结构不得修改主题文本、父子关系、同级顺序、Marker、备注、链接或其他内容。
- 结构切换后节点与连接线不得明显重叠，并能通过适配画布查看完整结果。

### 标签与筛选

- 每个主题支持零个或多个文本标签。
- 支持新建、编辑、删除和复用已有标签。
- 同一主题内的标签可以保持用户顺序，也可以选择自动排序。
- 点击标签可以突出所有具有该标签的主题，并弱化其他主题。
- 筛选面板支持组合以下条件：主题文本、标签、Marker、优先级、状态、是否包含备注。
- 筛选只影响可见性或视觉强调，不修改导图数据、层级和折叠状态。
- 清除筛选后恢复筛选前的正常导图显示。

### 自动编号

- 支持为选中主题的同级集合应用编号。
- 至少支持阿拉伯数字、英文字母和罗马数字三类编号样式。
- 支持普通同级编号和继承父级的层级编号。
- 支持从指定主题重新开始编号。
- 移动、插入或删除主题后，编号按照当前结构顺序自动更新。
- 编号属于独立语义数据，不直接写入主题文本；取消编号后原主题文本保持不变。
- 编号可以批量应用到同级主题，并可以统一移除。

### Callout

- 普通主题和 Floating Topic 均可添加 Callout。
- 一个主题首版最多包含一个 Callout；后续如需多个 Callout 再单独扩展。
- Callout 支持创建、编辑文本、删除、移动显示方向和基础样式设置。
- Callout 不参与主题父子层级，不改变主题顺序。
- Callout 随主题移动、复制、粘贴、删除和导出。

### 图片

- 支持从本地文件选择 PNG、JPEG、WebP、GIF 或 SVG 图片。
- 支持在浏览器允许时从剪贴板粘贴图片。
- 图片作为主题内容的一部分展示，支持调整宽度、恢复原始比例和删除。
- 用户可以为图片填写替代文本，图片加载失败时显示安全占位和替代文本。
- 对单张图片和单张导图的媒体总量设置明确限制；超出限制时给出可恢复的错误，不破坏当前导图。
- 复制主题、复制导图和内部 JSON 往返时保留图片引用及可编辑性。
- SVG/PNG 导出包含实际可见图片；导出失败时明确说明原因。

### 数学公式

- 支持通过 LaTeX 源文本创建和编辑块级数学公式。
- 编辑器显示公式预览，并对无法解析的 LaTeX 给出明确错误。
- 无效公式不会覆盖最后一次有效内容，用户可以返回继续修改源文本。
- 公式跟随主题移动、复制、粘贴、删除、自动保存和导出。
- 首版不要求所见即所得公式编辑，也不要求化学结构专用编辑器。

### 主题、分支与地图样式

- 主题至少提供矩形、圆角矩形、胶囊、下划线和无边框五类形状。
- 支持设置主题填充色、边框色、边框宽度和边框样式。
- 支持设置整段主题文本的字体、字号、字重、斜体、删除线、颜色和对齐。
- 支持设置分支线颜色、宽度、实线/虚线和连接形状。
- 支持为导图设置背景色、默认字体和一组内置 theme。
- 支持复制样式、粘贴样式和恢复默认样式；样式 clipboard 与主题内容 clipboard 相互独立。
- 支持将样式应用到当前主题、同级主题、全部后代或同层级主题，并在执行前明确作用范围。
- 多选样式面板应显示相同值或混合状态，批量修改只覆盖用户实际选择的属性。
- 首版只要求整段主题文本样式，不要求在同一主题文本内部混合多种字体或颜色。

### 关系线、边界、概要与 Callout 样式

- 关系线支持选择线形、颜色、宽度、虚线样式、起点/终点样式和标签文字样式。
- 关系线支持拖动控制点调整路径；布局变化后保留用户意图或回退到安全默认路径。
- 边界支持设置形状、填充、透明度、边框颜色、宽度和虚线样式。
- 概要支持设置括号/连接线样式、颜色、宽度和概要主题样式。
- Callout 支持设置形状、填充、边框和文字样式。
- 上述对象可以独立选择、编辑、删除、撤销和重做。

### 分支聚焦与编辑导航

- 用户可以将任意普通主题设为当前聚焦根节点，只显示该主题及其后代。
- 聚焦状态提供可见面包屑，用户可以返回父级或整张导图。
- 聚焦只属于编辑视图状态，不改变真实 root 和父子关系。
- 搜索或筛选结果位于当前聚焦范围外时，应用应提示用户退出聚焦或切换到对应分支。
- 提供快速回到中央主题、上一个选中主题或当前编辑主题的导航入口。

### 可靠性、兼容性和导出

- 所有新增持久化编辑操作都必须进入统一 undo/redo history。
- 用户撤销后执行新编辑时，redo history 按现有规则清除。
- 自动保存必须包含本阶段新增的结构、坐标、标签、编号、Callout、图片、公式和样式。
- 已有 MVP 导图无需用户手工转换即可打开，且原有内容和行为保持一致。
- 内部 JSON 导入导出必须无损往返本阶段全部可编辑数据。
- 对未知未来字段继续采用安全失败或兼容保留策略，不得静默删除用户内容。
- SVG/PNG 导出应包含当前完整导图的新增可见内容，不受当前 viewport 裁切。
- 500 个普通主题并包含合理数量标签、编号和 Callout 的导图仍可完成编辑、平移、缩放、筛选、聚焦和自动保存。
- 50 个主题连续键盘录入、移动和调整层级过程中不得明显阻塞或丢失输入。

## 范围外

- 完整 Xmind 文件导入导出、像素级界面复刻或全部快捷键兼容。
- Matrix、Fishbone、Timeline、Brace Map、Tree Table 等全部 Xmind 结构在同一阶段一次性实现。
- 任意自由画布、流程图形状库、手绘、便签墙或通用白板。
- 同一主题文本内部的任意富文本 span、Markdown 编辑器或复杂表格。
- 通用文件附件、PDF/Word/Excel 内嵌、音频录制和视频嵌入。
- AI 生成、AI 总结、AI 图片转导图或自动内容扩写。
- Outline 独立编辑模式、Pitch Mode、演示动画和幻灯片。
- 云同步、账号体系、版本历史、多人协作、评论和分享权限。
- 模板市场、自定义 theme 文件导入、插件系统和脚本扩展。
- 用户自定义工具栏、拖动重排工具按钮、保存个人工具栏布局或第三方工具按钮扩展。
- 小程序、PWA、移动端或桌面原生客户端实现；本阶段只保证核心数据结构为后续平台保留复用能力。

## 验收标准（Acceptance Criteria）

### AC-01 已有导图兼容

给定用户已有一张由 MVP 保存的导图，当升级后的编辑器打开、编辑并再次保存该导图时，原有主题树、样式、Marker、备注、链接、关系线、边界、概要和折叠状态保持一致，用户不需要手工迁移。

### AC-02 插入父主题

给定任意非 root 主题被选中，当用户执行“插入父主题”时，新主题占据原主题在原 parent 中的位置，原主题成为新主题的第一个 child；撤销和重做后结构精确恢复。

### AC-03 删除单个主题

给定一个包含多个 child 的非 root 主题，当用户执行“仅删除当前主题”时，其 child 按原顺序提升到原 parent 对应位置，任何后代都不丢失；撤销后原结构完整恢复。

### AC-04 键盘重排与层级调整

给定画布获得焦点且普通主题被选中，当用户使用约定快捷键移动同级顺序、提升层级或降低层级时，结构立即更新且保持有效；在 root、首项、末项或无合法 parent 等边界位置时不会产生损坏数据。

### AC-05 Floating Topic

给定用户双击画布空白区域或执行插入操作，当创建 Floating Topic 后，用户可以编辑、自由拖动、复制和设置样式；将其转换为普通主题或从普通主题转换回来时，内容和完整子树保持一致。

### AC-06 整图结构切换

给定一张多层导图，当用户在四种必需结构之间切换时，主题父子关系和顺序不变，节点与连接线重新布局且无明显重叠，保存、重新打开和撤销/重做后结构选择保持正确。

### AC-07 Mixed Structure

给定某个主要分支被选中，当用户为该分支设置与整图不同的受支持结构时，只有该分支及其后代使用覆盖结构，其他分支保持原布局；取消覆盖后恢复整图默认结构。

### AC-08 主题宽度与换行

给定一个长文本主题，当用户设置固定宽度时，文本在主题内安全换行且连接线、选择框和文本 editor 对齐；恢复自动宽度后，节点重新适应内容。

### AC-09 标签与筛选

给定多个主题具有不同标签、Marker、状态和备注，当用户组合筛选条件时，只突出或显示符合条件的主题并给出匹配数量；清除筛选后所有原数据、折叠状态和选择状态保持安全。

### AC-10 自动编号

给定一组同级主题已启用普通或层级编号，当用户插入、删除或重新排序其中主题时，编号自动按当前顺序更新；取消编号后主题原始文本不变。

### AC-11 Callout

给定任意主题，当用户添加并编辑 Callout 后，Callout 与主题保持关联但不进入主题层级；移动、复制、保存、撤销/重做和 JSON 往返后文本与样式保持一致。

### AC-12 图片内容

给定用户选择符合类型和大小限制的本地图片或粘贴图片，当插入完成后，图片显示在目标主题中并可调整尺寸、填写替代文本和删除；重新打开、复制主题和导出 SVG/PNG 后图片保持可见。

### AC-13 数学公式

给定用户输入有效 LaTeX，当提交后主题显示可读公式并保存源文本；输入无效 LaTeX 时应用指出错误且不覆盖最后一次有效公式。

### AC-14 精细样式

给定单个或多个主题被选中，当用户修改形状、文字、边框或分支线属性时，只有明确修改的属性发生变化，混合值被正确表达，结果可撤销并在保存后恢复。

### AC-15 样式复制与批量应用

给定来源主题具有自定义样式，当用户复制样式并粘贴到目标主题，或应用到同级/后代时，目标范围获得相同的受支持样式但不改变文本、结构或 metadata；重置样式后恢复当前 theme 的默认值。

### AC-16 增强对象样式

给定关系线、边界、概要或 Callout 被选中，当用户修改其受支持样式时，画布立即更新，选择和编辑状态清晰，撤销、保存和导出后结果一致。

### AC-17 分支聚焦

给定用户聚焦一个非 root 主题，当进入聚焦状态后只显示该主题及其后代，并显示可返回的面包屑；用户在聚焦状态下编辑的内容保存到原导图结构，退出聚焦后其他分支保持不变。

### AC-18 Undo、Redo 与自动保存

给定用户连续执行结构切换、Floating Topic、标签、编号、Callout、图片、公式和样式操作，当逐步 undo/redo 或刷新重新进入时，每一步和最后一次成功保存状态都保持一致，不出现部分恢复或孤立数据。

### AC-19 JSON 与图片导出往返

给定一张包含本阶段全部新增数据的导图，当导出并重新导入内部 JSON 时，受支持数据保持等价且可继续编辑；导出 SVG/PNG 时，完整可见结构、图片、公式、编号、Callout 和样式不被 viewport 裁切。

### AC-20 规模与可访问性

给定 500 个主题并包含合理数量新增元素的导图，当用户执行布局切换、筛选、聚焦、平移、缩放和自动保存时，应用不崩溃且操作可完成；新增控件具备可识别名称、键盘焦点和必要的状态提示。

### AC-21 基本编辑工具栏完整性

给定用户进入导图编辑器，当工具栏加载完成后，用户可以从直接按钮或明确分组菜单找到 History、主题、结构、插入、样式和视图范围内的全部必需操作；执行任一持久化编辑后，结果与对应快捷键或 inspector 操作一致，并可正常 undo/redo 和自动保存。

### AC-22 工具栏上下文状态与可访问性

给定无选择、Root、普通主题、Floating Topic、多选主题或增强对象等不同选择状态，当状态变化时，工具栏正确启用、禁用或标记相关操作，并解释不可用原因；用户可以仅用键盘浏览和执行全部可用操作，菜单关闭后焦点返回合理位置，窄窗口下收纳菜单仍保留全部必需功能。

### AC-23 编辑器视口、响应式布局与拖动文字选择

给定用户在宽度大于 960px 的桌面窗口打开导图，编辑器应占满可用视口且只在画布和检查器内部滚动；宽度不超过 960px 时，检查器移动到画布下方且全部文件操作仍可从“更多”菜单访问。每次新建、打开、导入或切换导图后，Root 以 100% 居中显示；“适应画布”不得放大小导图，只能在大型导图超出空间时缩小。用户从主题文字开始拖动时，不得出现浏览器文字选择，进入主题文本编辑后仍可正常选择文字。

## 边界情况

- 在 root、一级主题或唯一 child 上执行插入父主题、删除单个主题、提升或降低层级。
- 删除单个主题时，其 child 中同时包含折叠分支、关系线、边界、概要或被筛选主题。
- 普通主题与 Floating Topic 互转时包含完整子树、图片、公式、Callout 和 relationship reference。
- Floating Topic 被拖到画布极远位置、与普通节点重叠，或导出 bounds 因自由位置变得极大。
- 双向 Mind Map 中一级主题在左右两侧移动或重新排序。
- Mixed Structure 嵌套过深，或切换结构后节点尺寸发生明显变化。
- 固定宽度主题包含中文、英文长单词、换行、emoji 或特殊字符。
- 多选主题具有不同标签、编号、形状、字体或分支线样式。
- 层级编号中途重新开始，随后移动 parent、插入同级或删除编号起点。
- 标签为空、重复、大小写不同、包含逗号或非常长。
- Callout 文本为空、很长，或主题折叠后 Callout 是否显示。
- 图片格式伪装、解码失败、尺寸极大、透明背景、动画 GIF、SVG 含潜在不安全内容或剪贴板权限被拒绝。
- 导图媒体总量接近浏览器存储上限，自动保存失败或导出内存不足。
- LaTeX 为空、语法错误、极长、包含不支持命令或渲染尺寸异常。
- 关系线控制点在布局切换、主题移动或结构切换后失去合理位置。
- 聚焦分支内执行搜索、筛选、删除、移动到聚焦范围外或 undo。
- 旧导图缺少新增字段，或导入文件包含未知结构、未知样式和未来版本字段。
- 用户在自动保存进行中快速连续切换布局、粘贴图片和执行 undo/redo。
- 工具栏初始化时导图仍在加载、当前选择已被删除，或 history 状态在菜单打开期间发生变化。
- Root、Floating Topic、多选主题和增强对象之间快速切换，导致工具栏可用状态频繁更新。
- 浏览器缩放或窗口宽度变化使工具栏空间不足，overflow menu 打开后窗口再次改变尺寸。
- Tooltip、下拉菜单或颜色选择器打开时用户按 `Esc`、切换语言、撤销操作或把焦点移回画布。
- 工具栏按钮对应快捷键被平台或浏览器占用，或用户处于 IME composition 和文本编辑状态。
- 顶栏因语言、标题或窗口宽度变化发生换行时，编辑区仍应使用实际剩余高度，不依赖固定像素扣减。
- Inspector 内容高度远超视口时，只允许 Inspector 自身滚动，不得把桌面页面根滚动区域撑高。
- 用户缩放、平移或编辑导图后，不得因为 document revision、ResizeObserver 或布局重算再次自动居中。

## 假设

- 本阶段继续只交付桌面 Web，不同时开发 PWA、小程序或移动端 UI。
- Xmind 只作为功能分类和交互效率参考；本产品保持独立的数据模型、视觉设计和快捷键体系。
- 优先实现思维导图领域内高频编辑能力，不以一次性覆盖 Xmind 全部结构和全部高级功能为目标。
- 已有 Web Mind Map MVP 的验收标准继续作为回归要求，不在本规格中逐条重复。
- 图片优先采用本地可持久化方案；具体存储方式、压缩策略和大小限制在技术计划阶段确定。
- 首版公式使用 LaTeX 源文本和安全渲染，不提供复杂所见即所得公式编辑器。
- 首版主题文字仍以整段样式为单位，不支持同一主题内部的任意富文本 span。
- 首版一个主题最多一个 Callout，以控制数据模型和交互复杂度。
- 首版 mixed structure 只覆盖明确列出的结构组合；其余结构在后续版本按真实使用需求扩展。
- 首版工具栏采用产品预设分组，不提供用户自定义按钮、顺序或工具栏布局。
- 工具栏是现有 Command 和 editor session 的操作入口，不产生新的领域数据类型。
- 桌面 Chrome 和 Edge 是主要验收浏览器，Firefox 和 Safari 继续作为尽力兼容目标。
- 所有新增领域数据必须保持平台无关，不能在 core model 中依赖 DOM、Browser File、Canvas 或 IndexedDB 类型。
