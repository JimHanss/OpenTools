# 主题编辑与画布交互优化

## 目标

优化 Web 思维导图编辑器中主题文本、直接编辑、画布拖动、框选、快捷创建、折叠控制和主题拖放的交互体验。主题在普通、悬浮、选中、编辑和拖动状态之间切换时，应保持稳定的尺寸、样式和位置，避免非预期的 UI 跳动，同时让高频的画布导航与主题创建操作更直接。

## 用户

- 使用鼠标在桌面浏览器中持续创建和整理思维导图的用户。
- 需要编辑长文本主题，并希望主题尺寸自然适应内容的用户。
- 依赖拖动画布、框选多个主题和拖放子树完成结构整理的用户。
- 希望通过主题周边快捷入口快速创建同级或子主题的用户。

## 用户场景

### 1. 自适应主题宽度

用户输入较短文本时，主题块随文字宽度自然撑开；只有文本达到允许的最大宽度后才自动换行并向下扩展。用户无需手动调整普通主题的宽度，也不会看到短文本被过早换行。

### 2. 无跳动的主题编辑

用户双击主题或通过键盘进入编辑时，编辑控件沿用编辑前主题块的背景、形状、字体、字号、字重、文字颜色、对齐、内边距和尺寸，不额外显示输入框 border。编辑开始、输入、提交和取消期间，主题及周边节点不应因为编辑控件自身样式产生可感知的位置或尺寸跳动。

### 3. 进入编辑后替换全部文字

用户进入主题编辑状态时，现有主题文字默认全部选中。用户可以直接输入新内容完成整体替换，也可以通过方向键或鼠标取消全选后进行局部修改。

### 4. 左键拖动画布与 Alt 框选

用户在画布空白区域按住鼠标左键拖动即可平移画布。需要框选多个主题时，用户按住 `Alt` 再用鼠标左键拖出选择框。原有鼠标右键拖动画布不再作为主要交互入口。

### 5. 主题周边快捷创建

用户选中一个非中央主题后，主题右侧外部显示一个加号按钮，主题下方外部显示另一个加号按钮。点击右侧加号创建该主题的子主题；点击下方加号创建该主题的下一个同级主题。新主题创建后立即进入文本编辑状态。

### 6. 按需显示折叠控件

具有子主题的主题仅在自身被选中时显示左上角的减号折叠按钮。未选中时该按钮完全隐藏且不占用可见布局空间。已经折叠且存在隐藏子主题的主题仍应提供可发现的展开入口，但该入口同样只在主题被选中时显示。

### 7. 清晰的主题拖动反馈

用户拖动选中主题或子树时，原位置的主题以半透明方式保留，作为来源位置提示；同时显示一个独立的拖动浮层跟随鼠标。浮层应保持主题原有的主要视觉样式，并与实际 drop target 提示相互独立。完成或取消拖动后，来源主题恢复正常透明度，浮层立即消失。

### 8. 稳定的悬浮状态

鼠标进入或离开主题时，只允许出现不改变布局尺寸的视觉反馈。悬浮不得新增会占据空间的 border、padding 或控件，也不得改变主题测量结果、连接线位置或相邻主题位置。

## 范围内

- 普通主题和 Floating Topic 的自动宽度、最大宽度与换行表现。
- 主题文本编辑 overlay 的视觉一致性、尺寸稳定性和初始文字选择。
- 画布空白区域的鼠标左键平移。
- `Alt + 鼠标左键拖动` 框选主题。
- 选中非中央主题周边的子主题与同级主题快捷创建按钮。
- 折叠/展开按钮基于主题选择状态的显示规则。
- 普通主题和 Floating Topic 拖动时的来源半透明状态与跟随鼠标的拖动浮层。
- 主题 hover、selected、editing、dragging 和 collapsed 状态之间的稳定切换。
- 对上述行为的键盘、指针、布局和浏览器回归验证。

## 范围外

- 修改 `Enter`、`Tab`、`F2`、删除、撤销和重做等现有快捷键语义。
- 修改导图领域模型、文件 schema 或持久化格式。
- 新增触控手势、移动端专用长按交互或手写笔交互。
- 新增任意方向的快捷创建按钮或允许用户配置按钮位置。
- 改变主题拖放后的领域规则、非法 cycle 防护或 Command history 行为。
- 重做主题视觉设计、内置 theme 或 Inspector 样式系统。
- 将右键拖动画布改为其他新的右键菜单功能。

## 验收标准（Acceptance Criteria）

### AC-01 主题文字自然撑开并在最大宽度换行

给定一个使用自动宽度的主题，当文本宽度未达到当前主题允许的最大宽度时，主题块宽度随文字自然增长且文字不换行；当文本超过最大宽度时，主题宽度不再增长，文字自动换行并增加主题高度。中英文、空格、长单词、emoji 和混合文本均不得造成内容溢出或相邻主题重叠。

### AC-02 编辑状态保持主题原有外观

给定任意已渲染主题，当用户进入文本编辑状态时，编辑区域不显示额外 border，并与编辑前主题的形状、背景、字体、字号、字重、文字颜色、对齐、内边距、宽度和高度保持视觉一致。进入编辑、输入字符、提交和取消时，主题中心位置与相邻布局不得因编辑控件默认样式发生可感知跳动。

### AC-03 进入编辑时默认全选文字

给定一个包含已有文字的主题，当用户通过双击、`F2` 或创建后自动编辑进入编辑状态时，主题现有文字全部处于选中状态。用户直接输入时替换全部文字；用户按方向键、点击或拖动选择时，浏览器标准文本编辑行为仍然有效。

### AC-04 左键拖动画布

给定指针起点位于画布空白区域，当用户按住鼠标左键并移动时，viewport 按指针位移平移，不创建框选区域、不选择页面文字，也不修改导图 document。单击空白区域但未达到拖动阈值时，保持现有空白点击选择语义。

### AC-05 Alt 加左键执行框选

给定指针起点位于画布空白区域，当用户按住 `Alt` 并用鼠标左键拖动时，显示框选区域，并根据框选范围更新主题多选结果；该操作不得平移画布。释放 `Alt` 或鼠标、按下 `Escape`、窗口失焦或 pointer cancel 后，框选预览应正确结束且不留下临时 UI。

### AC-06 右侧加号创建子主题

给定一个已选中的非中央主题，当右侧加号可见且用户点击时，在该主题下创建一个新子主题，新主题立即被选中并进入文本编辑。操作进入现有 Command history、可撤销和重做，并触发自动保存。

### AC-07 下方加号创建同级主题

给定一个已选中的非中央主题，当下方加号可见且用户点击时，在该主题之后创建一个新的同级主题，新主题立即被选中并进入文本编辑。操作进入现有 Command history、可撤销和重做，并触发自动保存。

### AC-08 快捷创建按钮不干扰其他交互

右侧和下方加号仅在恰好选中一个允许创建相应主题的非中央主题时显示。按钮位于主题可视边界外，不覆盖主题文字、折叠控件、连接线或拖动命中区域；缩放和平移后仍与主题保持正确相对位置。多选、增强对象选择、文本编辑和主题拖动期间不显示这些按钮。

### AC-09 折叠按钮仅在选中时显示

给定一个具有子主题或已折叠隐藏子主题的主题，当该主题未选中时，不显示折叠/展开图标；当该主题被选中时，在左上角显示对应图标。图标出现或消失不得改变主题 bounds、文字位置、连接线端点或整体布局。

### AC-10 拖动时保留半透明来源主题

给定一个已选中的可拖动主题，当拖动超过启动阈值后，原位置的主题及其必要来源视觉以半透明状态保留，且原布局位置不变。半透明只影响显示，不修改 document、scene bounds 或 drop 计算。

### AC-11 拖动浮层跟随鼠标

主题拖动开始后，显示独立浮层并持续跟随鼠标位置。浮层应展示被拖主题的文字、形状和主要样式，不得被原 SVG 布局裁切，也不得拦截 drop target 命中。drop 成功、取消、`Escape`、窗口失焦或 pointer cancel 后，浮层和来源半透明状态必须同时清除。

### AC-12 悬浮主题不产生 UI 跳动

给定鼠标反复进入和离开任意主题，当 hover 状态变化时，主题的几何 bounds、文本测量结果、连接线端点、相邻主题位置和 viewport scroll size 保持不变。任何 hover 高亮使用不参与布局的视觉方式实现。

### AC-13 现有输入与拖放能力保持兼容

调整后，双击编辑、`F2` 编辑、`Enter` 新建同级、`Tab` 新建子级、主题自身左键拖放、Floating Topic 拖动、非法 cycle 拒绝、撤销/重做、自动保存、搜索、缩放和导出仍按现有规则工作。主题上的左键拖动继续表示拖动主题，只有画布空白区域的左键拖动改为平移。

### AC-14 响应式与可访问性

在桌面和窄窗口布局中，快捷创建与折叠控件不得造成页面横向溢出。加号和折叠/展开控件具有明确的 accessible name、可见焦点状态和足够的点击区域；仅用键盘的现有主题创建路径继续可用。`Alt` 框选不得在文本输入框或主题编辑状态中拦截浏览器正常输入行为。

## 边界情况

- 主题为空、仅包含空格、单个超长英文单词、连续中文、emoji 或多行粘贴文本。
- 主题使用固定宽度时，继续遵循用户指定宽度，不被自动宽度规则覆盖。
- 主题字号、字重、字体、内边距、边框宽度或 shape 被自定义后进入编辑。
- 编辑器缩放比例不是 100%，或画布已经平移到较远位置。
- 选中 root、Floating Topic root、普通叶子主题、已有多个子主题的主题或折叠主题。
- 多选主题、选择关系线/边界/概要/Callout、处于分支聚焦或筛选状态。
- 加号按钮靠近 viewport 边缘、Inspector 边缘或其他主题时。
- 鼠标从主题文字、折叠图标或快捷创建按钮开始移动。
- 用户尚未超过拖动阈值就释放鼠标，或拖动中按 `Escape`、切换窗口、丢失 pointer capture。
- 拖动包含图片、公式、Callout、折叠后代或复杂样式的主题。
- `Alt` 被操作系统或浏览器用于菜单焦点时，应用仍应在画布获得 pointer 事件的情况下正确识别框选意图。
- hover、selected、editing 和 dragging 状态快速连续切换。

## 假设

- “主题右边的加号”表示创建子主题；“主题下边的加号”表示在当前主题之后创建同级主题。
- 快捷创建按钮不对中央主题显示；中央主题继续通过工具栏、`Enter` 或 `Tab` 创建下一层主题，避免“同级主题”语义不成立。
- 自动宽度仍受产品统一的最大主题宽度限制；具体像素值沿用或集中到现有主题测量配置，不在本规格中改变用户可配置的固定宽度语义。
- 左键平移仅从画布空白区域开始；从主题开始的左键拖动继续执行主题拖放。
- 鼠标右键拖动画布可以保留为兼容入口，但左键拖动成为默认且主要的画布平移方式。
- 拖动浮层只需表现被拖动的根主题及其主要样式；完整子树仍通过来源状态和 drop 提示表达，不要求浮层复制整棵子树的全部渲染内容。
- 折叠与展开共用主题左上角同一位置的状态图标；未选中时两种状态都隐藏。
