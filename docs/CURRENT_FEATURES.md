# OpenTools 现有功能

本文档总结当前 Web MVP V2 已实现的用户功能。

## 导图库

- 新建思维导图
- 打开已有导图
- 重命名导图
- 创建导图副本
- 删除导图
- 自动保存编辑内容到当前浏览器
- 导入 OpenTools JSON 文件

## 主题

- 双击主题或按 `F2` 编辑主题文字
- 进入编辑时默认全选文字，编辑器外观与编辑前主题保持一致
- 主题文字在最大宽度以内自然撑开主题，超过上限后自动换行
- 按 `Enter` 添加同级主题
- 按 `Tab` 添加子主题
- 单选普通非根主题后，可点击右侧加号创建子主题、下方加号创建下一个同级主题
- 单选 Floating Topic 根后，可点击右侧加号创建子主题
- 按 `Delete` 或 `Backspace` 删除主题及其子树
- 创建主题副本
- 复制、剪切和粘贴主题
- 插入父主题
- 仅删除当前主题，并将子主题提升一级
- 选中有子主题的主题后显示折叠或展开控件
- 将主题及其子树转换为自由主题
- 将自由主题重新接入普通主题树
- 聚焦当前分支，并通过面包屑返回或退出聚焦

## 主题选择与移动

- 单击选择一个主题
- 按住 `Ctrl` 或 `Cmd` 单击选择多个主题
- 按住 `Alt` 并在画布空白处用鼠标左键拖动，框选多个主题
- 拖动主题调整同级顺序
- 拖动主题更换父主题
- 拖动完整子树
- 拖动时原主题半透明，并显示跟随鼠标的主题浮层
- 使用 `Alt+↑` 和 `Alt+↓` 调整同级顺序
- 使用 `Alt+←` 和 `Alt+→` 提升或降低主题层级
- 自动阻止把主题移动到自身或其后代中

## 撤销与重做

- 使用工具栏撤销或重做编辑
- 按 `Ctrl/Cmd+Z` 撤销
- 按 `Ctrl/Cmd+Shift+Z` 或 `Ctrl+Y` 重做
- 支持主题、结构、样式和增强对象等核心操作的撤销与重做

## 画布

- 使用鼠标左键拖动画布空白区域进行平移
- 兼容使用鼠标右键拖动画布
- 使用滚轮缩放画布
- 通过工具栏放大或缩小
- 一键适应画布
- 一键居中所选主题
- 新建或打开导图时以 100% 居中显示根主题
- 大型导图自动缩小到合适范围
- 拖动主题时不会误选主题文字
- 鼠标悬浮主题时不改变主题或相邻布局几何

## 自由主题

- 在画布中创建自由主题（Floating Topic）
- 自由拖动自由主题的位置
- 为自由主题添加普通子主题
- 将普通主题及完整子树转换为自由主题
- 将自由主题及完整子树拖回普通主题树
- 自动整理主树时保留自由主题位置

## 导图结构

- 逻辑图（向右）
- 逻辑图（向左）
- 双向思维导图
- 树状图
- 组织结构图
- 为整张导图切换默认结构
- 为单独分支设置不同结构
- 在同一张导图中组合多种结构
- 一键整理布局

## 标签、标记与编号

- 创建、重命名、改色和删除标签
- 为单个或多个主题添加标签
- 添加优先级、状态和图标标记
- 添加阿拉伯数字、英文字母或罗马数字编号
- 使用同级编号或层级编号
- 设置编号起始值
- 主题顺序变化后自动更新编号

## 搜索与筛选

- 按主题文字搜索
- 在搜索结果之间跳转
- 按标签筛选
- 按优先级筛选
- 按状态筛选
- 按是否包含备注筛选
- 使用 AND 或 OR 组合筛选条件
- 突出显示匹配主题及其上下文路径
- 清除筛选时不改变导图结构和折叠状态

## 主题内容

- 添加和编辑备注
- 添加和编辑链接
- 插入本地图片
- 设置图片尺寸、比例和替代文字
- 插入和编辑 LaTeX 数学公式
- 使用 MathJax 预览和渲染公式

## 关系与增强对象

- 在两个主题之间创建关系线
- 编辑关系线文字、颜色、宽度、线型和端点
- 拖动控制点调整关系线路径
- 为多个主题创建边界
- 为多个主题创建概要
- 为主题创建 Callout 标注
- 编辑 Callout 的文字、位置、方向和样式
- 独立选择、编辑和删除关系线、边界、概要及 Callout

## 主题样式

- 设置主题形状
- 设置固定宽度或内容自适应宽度
- 设置背景颜色
- 设置边框颜色、宽度和线型
- 设置字体、字号和字重
- 设置斜体和删除线
- 设置文字颜色和对齐方式
- 设置分支线颜色、宽度、线型和连接形状
- 将样式应用到当前主题、同级主题、后代主题或同层主题
- 复制和粘贴主题样式
- 重置主题样式
- 使用经典、海洋、森林和晚霞主题方案

## 文件导入与导出

- 导入 OpenTools schema v1、v2 和 v3 JSON
- 自动将旧版导图迁移到当前格式
- 导出可继续编辑的 JSON
- 导出包含图片资源的 JSON bundle
- 导出完整 SVG 图片
- 导出完整 PNG 图片
- 导出时包含自由主题、图片、公式和增强对象
- PNG 超出浏览器限制时自动回退为 SVG
- 无效或损坏的导入文件不会覆盖当前导图

## 本地存储与可靠性

- 使用浏览器 IndexedDB 保存导图和图片
- 编辑过程自动保存
- 保存失败时保留当前编辑内容和撤销历史
- 图片写入、导图保存和资源清理采用安全事务
- 检查图片大小、资源总量和文件校验值
- 浏览器剪贴板不可用时保留应用内复制粘贴能力

## 界面与语言

- 支持中文和英文界面
- 自动检测浏览器语言
- 保存用户选择的界面语言
- 窄屏时将次要工具收纳到“更多”菜单
- 窄屏时将主题检查器移动到画布下方
- 支持工具栏键盘导航和不可用原因提示
- 输入法组合输入期间不会误触发主题快捷键

## 当前范围外

- 云同步与账号系统
- 多人实时协作、评论和权限
- AI 生成、总结或内容扩写
- 完整 Xmind 或 OPML 文件兼容
- 通用白板和流程图编辑
- PWA 安装
- 小程序、原生移动端和桌面客户端
